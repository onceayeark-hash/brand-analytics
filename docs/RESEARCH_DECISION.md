# 商品リサーチ・競合リサーチ機能 廃止決定記録

**決定日：2026-06-03**
**決定者：オーナー（ブラウザ Claude との設計議論を経て）**
**ステータス：確定・覆さない**

---

## 結論

**ブランドリサーチ・競合リサーチ機能（STAGE3）は本体から分離・保留とする。**
URL fetch 方式のツール実装は行わない。
SaaS 機能として sold データの自動取得は実装しない。

---

## 経緯（2026-06-02〜03 検証）

### 当初の設計構想

STAGE3 として「ブランドリサーチ」タブを新設し、eBay の sold（成約）データを蓄積・分析することで
同業者に対してツールを差別化する計画だった。

FX のヒストリカルデータと同じ考え方で、蓄積するほど価値が増す設計を目指した。

### 検証した手段と結果

#### 1. Terapeak CSV エクスポート
- **結論：不可**
- Terapeak（eBay Product Research）にはネイティブな CSV エクスポートボタンが存在しない
- コピー→Excel→CSV の手動作業は非現実的
- Terapeak は無料ウェブツール。API も有料データ販売も存在しない

#### 2. eBay sold 検索ページの HTML 保存
- **結論：一覧ページは不可・個別ページのみ可**
- sold 検索一覧（`/sch/i.html?LH_Sold=1`）は JavaScript で動的描画される SPA のため
  HTML 保存では空のシェルしか取れない
- 個別商品ページ（`/itm/ITEMID`）は HTML 保存が有効
- ただし個別ページは 1件ずつクリック→保存が必要で大量取得には不向き

実測（ginzo-net9426 の HERMES 商品ページ保存・2026-06-03）：
```
取得できたもの：タイトル・価格・送料・コンディション・セラー名・画像URL（11枚）
取得できなかったもの：成約日・出品日（JavaScript 動的描画のため）
```

#### 3. URL fetch 方式（PM カレッジリサーチシート方式）
- **結論：採用しない（事業判断）**
- 技術的には動作する（知人ツールが稼働中）
- しかし「ユーザーが URL を貼ってもリクエスト主体はツール（サーバー）」であり
  eBay ToS の「automated means（robot/spider/scraper）」に該当する
- PM カレッジが問題化していないのは個人・小規模だからであり、合法だからではない
- **当社は SaaS 化・Growth Check 申請を控えた法人アカウント**
  実装すると販売アカウント・Developer 資格の停止リスクに直結する

#### 4. Marketplace Insights API（`buy.marketplace.insights`）
- **結論：現時点では一般開発者への承認はほぼ不可**
- Growth Check 通過後に申請可能だが、コミュニティ報告では「approved partners のみ」「拒否される」事例多数
- eBay の意図：Terapeak で囲い込み、API 経由の競合ツールを排除
- **ただし Growth Check 通過後に正攻法で申請する価値は残す**

#### 5. ZIK Analytics API
- **結論：API 自体が存在しない**
- ZIK Analytics（月 $29.99〜）はブラウザ SaaS ツール。開発者 API は提供されていない

---

## 採用する方針

### 短期（現在〜Growth Check 通過まで）
- リサーチ・競合分析機能は本体からスコープ外
- コア機能（仕入シミュレーター・アカウント管理・取引記録・ダッシュボード）に集中
- 個別ページ HTML 保存は「オーナー個人の手動リサーチ」用途のみ・SaaS 機能には載せない

### 中期（Growth Check 通過後）
- Marketplace Insights API を正攻法で申請
- 申請の訴求：「日本人 eBay セラー支援 = eBay GMV 増加」「競合サービスでない」
- 承認されれば STAGE3 リサーチ機能を実装

## 教訓

- eBay の sold データは「ブラウザで見る（Terapeak）」と「API で取る」が意図的に分離されている
- 個人・小規模ツールが問題化しない事例を「合法の証明」として採用根拠にしてはいけない
- 法人・SaaS として判断する基準は「技術的に動くか」ではなく「事業として踏めるか」
- この壁を越えようとする手段はほぼすべて ToS グレーゾーンまたは明確な違反
